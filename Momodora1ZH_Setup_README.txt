Momodora1ZH_Setup.exe — 简体中文一键汉化安装器 v0.1.0

使用
1. Release 压缩包中直接双击 Momodora1ZH_Setup.exe；源码仓库中请打开 Momo1_151_Chinese_Patch/Momodora1ZH_Setup.exe。
2. 选择包含 momo1_v151.exe 和 data\graphic 的 Momodora 1.51 游戏根目录。
3. 可先点“检查原版”；通过后点“一键安装汉化”。
4. 在游戏目录启动 momo1_v151_zh.exe。

无 Python 依赖 / Windows x64。安装器已内嵌补丁引擎、清单和中文图集；目标电脑不需要安装 Python、额外 DLL、字体或联网。

保留规则
- 不覆盖原版游戏 EXE，不修改存档或系统设置。
- 生成 momo1_v151_zh.exe、中文图集和一份校验安装记录。
- 可重新运行安装器完成卸载；会拒绝删除被修改的文件。
- 请先备份存档。汉化版仍需要同一目录的全部原版游戏资源。
