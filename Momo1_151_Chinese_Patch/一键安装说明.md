# 一键安装器

1. 从[本非官方补丁项目的 Release 页面](https://github.com/hhnhhw/momodora1-zh-patch/releases)获取独立文件 `Momodora1ZH_Setup.exe`，并将它与同一 Release 提供的 `Momodora1ZH_Setup_README.txt`、许可文件放在一起。它是 Windows x64 单文件 GUI，目标电脑不需要安装 Python。
2. 运行安装器；用“浏览…”选择包含 `momo1_v151.exe` 的完整原版游戏根目录。
3. 可先点“检查原版”；确认版本通过后点“一键安装汉化”。
4. 完成后在同一游戏目录启动 `momo1_v151_zh.exe`。

安装器只支持官方 **Momodora 1.51** 原版，SHA-256：

```text
97b6419b3def0f9133a6b1322d113f3ed22b395fbf5d3eaa6dd8dc2dd406e84a
```

它会额外生成中文图集 `data/graphic/momo1_zh_text.png` 与校验记录，不会覆盖原版 EXE、存档、设置或资源。发现版本不符、同名未知文件或被修改的汉化文件时会停止，不强制覆盖/删除。

若 Windows SmartScreen / 杀毒软件提示该工具是未知或未签名程序，这是因为它为本项目自构建、未做代码签名，并不是微软发行的已验证安装器。可在运行前核对 GitHub 的公开源码与本目录 `oneclick_build_report.json` 中 SHA-256。若不放心，请不要运行；也可使用 Python 3.9+ 执行 `安装汉化.cmd`，或自己从源代码构建。

此安装器及补丁为非官方项目。请先确认你有原版游戏；不要把原版游戏或汉化整合 EXE 再发布。
