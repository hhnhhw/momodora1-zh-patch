# Momodora 1.51 简体中文汉化补丁（0.1 测试版）

## 安装后启动

本仓库不含已生成的游戏 EXE。请先按下文将补丁安装到原版游戏目录，再运行该目录新生成的 `momo1_v151_zh.exe`，或双击 `启动中文测试版.cmd`。

**不要把汉化 EXE 单独挪到别处。** 它仍依赖原游戏的 `data`、音频 DLL、配置，以及新增的 `data/graphic/momo1_zh_text.png`。原版 `momo1_v151.exe` 没有覆盖；运行原版即可回到英文。

## 覆盖内容

共 91 条翻译/显示映射，包含：

- 开始提示、三项主菜单、最佳时间标签、计时 HUD、保存提示；
- 新游戏序章的三段叙述；
- 已识别的普通 NPC、武器教程、首领与结局母亲对白；
- 暂停界面 15 项物品的名称与说明（30 条）；
- 片尾职务、鸣谢说明和出品文字。

原作者、参与者署名及版权文字保留原文。标题 Logo、烘焙在原始图片中的文字、引擎错误弹窗和开发测试房间文本未承诺汉化。未完成全流程通关回归，故本版明确标为**测试版**，不是“100% 无遗漏正式版”。

## 技术方案

原版 Game Maker 7 运行器逐字节取字形，现有 Apple Kid 字体仅覆盖拉丁字符；直接写 UTF-8/GBK 会乱码。本补丁没有改系统区域，也不安装字体或 DLL：

1. 严格匹配原版 EXE 的 SHA-256；
2. 解压、解混淆游戏资源，使用 5 个原本为空的脚本槽添加中文绘制代理；
3. 修改 7 个经过边界和哈希确认的绘字事件以及 `say`、`pause_scr` 两个脚本；
4. 根据原英文内容查找中文预渲染图集，保留对话分页、条件和数值逻辑；
5. 缺失图集或未匹配的文字回退为原英文。

为了兼容旧引擎，图集采用黑色色键透明方式，而不是依赖 PNG alpha。运行汉化版不需要安装中文字体。

## 在另一份同版本游戏中安装

安装器需要 **Python 3.9 或更高版本**；运行已经生成好的汉化游戏则不需要 Python。

1. 保留原游戏完整目录，并自行备份存档。
2. 将整个 `Momo1_151_Chinese_Patch` 文件夹放在原版 `momo1_v151.exe` 旁边。
3. 双击 `安装汉化.cmd`，或在补丁目录运行：

   ```powershell
   py -3 apply_patch.py
   ```

4. 在游戏根目录运行新生成的 `momo1_v151_zh.exe`。

显式指定游戏位置：

```powershell
py -3 apply_patch.py --game-dir "D:\你的游戏目录"
```

只检查、完全不写文件：

```powershell
py -3 apply_patch.py --check
```

只支持以下原版：

```text
文件：momo1_v151.exe
大小：3,013,668 字节
SHA-256：97b6419b3def0f9133a6b1322d113f3ed22b395fbf5d3eaa6dd8dc2dd406e84a
```

安装器拒绝错误版本、已修改原版、未知同名输出；不联网，不下载或运行第三方补丁程序。补丁包不含完整游戏 EXE、反编译工程、原始图像或原游戏音频。

## 卸载与存档

双击 `卸载汉化.cmd`，或运行：

```powershell
py -3 apply_patch.py --remove
```

卸载仅删除与安装记录校验值相符的汉化 EXE、中文图集及安装记录。原版 EXE、设置、原资源和存档均不删除。若你改过汉化文件，卸载器会停下，不会强行删除。

汉化版和原版使用同一存档目录：`data/saves/slot1`。本补丁不改变游戏 ID、存档路径或存档结构，但尚未做所有存档场景回归，切换前仍建议备份。制作期间的按键/启动测试使用了独立测试目录，没有操作你的原存档。

## 测试与已知边界

- 原版 EXE 逐字节无改动回包通过；汉化 EXE 解包读回和引擎前缀不变校验通过。
- 安装、重复安装、只读检查、卸载、错误版本拒绝、未知同名文件保护共 6 项自动测试通过。
- 正常 Windows 进程环境已启动原版与汉化版；已进入第一场景并打开物品栏。中文开始提示、主菜单、序章三段文字以及“魔法叶”物品名/说明共 7 项实际截图检查，字形像素全部匹配图集；序章淡入透明度保留。
- 当前自动化工具在沙箱内启动原版也会产生打印机 RPC / Delphi “Printer selected is not valid” 异常，并误报游戏数据损坏；解除该启动隔离后原版正常。**不需要因此修改系统打印机、关闭安全软件或给游戏设置管理员运行。**
- 请以 `runtime_test_report.json` 记录的实际测试覆盖为准。未通关验证的首领、结局、全部缩放和所有道具组合不承诺无问题。
- 若仍有英文：确认启动的是 `_zh.exe`，且中文图集仍位于 `data/graphic/momo1_zh_text.png`。

## 修改译文和重新构建

`texts.json` 是 UTF-8 翻译表，图集坐标由构建器生成。安装器只需 Python 标准库；重新渲染中文图集才需要 Pillow 和本机可用中文字形（当前构建用 Windows 黑体）。没有分发字体文件。更换译文后必须重建图集、代理代码与校验清单；直接编辑 JSON 不会即时改变游戏显示。

工具目录中的解包/构建脚本仅面向这一份 SHA-256 的 1.51，不能泛用于其它 Game Maker 游戏。原作者保留游戏及原素材全部权利；请勿传播完整游戏、反编译资源或擅自售卖汉化整合包。公开发布补丁前，请另行确认游戏翻译、图像及字体字形的授权条件。
